# Research program

T.O.C.A.I.A has a stronger path to international relevance as a **research program** than as another monolithic OSINT application.

## Track A · Gap taxonomy

Develop and test a taxonomy that distinguishes:

- expected absence;
- suspicious absence;
- adversarial silence;
- natural absence;
- collection absence.

Each category must have observable criteria and explicit confounders.

## Track B · Behavioral signal classes

Organize signals by what they actually describe rather than by what an analyst hopes they imply:

- identity signals;
- activity signals;
- network signals;
- intent-related signals;
- stability signals.

A signal class is not an attribution. The research question is what can be inferred reliably, under which coverage and error rate.

## Track C · OSINT Pattern Library

Build a versioned pattern library with:

- pattern definition;
- minimum observables;
- known confounders;
- expected false-positive modes;
- safe synthetic example;
- counterexample;
- confidence guidance;
- references.

## Track D · Pensieve Intelligence Bench

Create reproducible synthetic investigation scenarios with known ground truth:

- synthetic personas;
- simulated graphs;
- controlled timelines;
- known missing events;
- adversarial but non-harmful noise;
- benchmark tasks and scoring.

This gives the project something OSINT badly needs: repeatable evaluation without turning real people into lab material.

## Track E · Recon engineering

Where collection code is introduced, separate:

- discovery;
- reconnaissance;
- surface mapping;
- controlled crawling.

The benchmark should measure coverage, reproducibility and provenance, not reward aggressive collection.
