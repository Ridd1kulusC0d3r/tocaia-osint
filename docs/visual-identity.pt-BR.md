# Identidade visual · T.O.C.A.I.A

## Conceito: a silhueta negativa

A referência visual é o contorno formado por observações ao redor de uma lacuna. A marca comunica atenção, método e incompletude. O espaço negativo deve representar uma pergunta investigativa aberta, nunca uma identidade reconstruída com exatidão.

**Assinatura:** Observar padrões. Testar hipóteses. Antecipar cenários.

**Frase editorial:** O vazio também levanta perguntas. A evidência determina o que podemos responder.

Evitar promessas como “forma exata de si mesmo”, “prever qualquer pessoa” ou “ninguém consegue se esconder”. Elas não são sustentadas pelo estado atual do projeto. Não usar contagens fictícias de perfis como se fossem resultados reais.

## Assets

- [Banner SVG, 1440 × 640](../assets/brand/tocaia-banner.svg): capa dos READMEs, apresentação do conceito.
- [Marca SVG, 256 × 256](../assets/brand/tocaia-mark.svg): símbolo geométrico com enquadramento, T e interrupção central.
- [Tokens CSS](../assets/brand/tokens.css): cores e tipografia para futuras interfaces.

Os SVGs são vetoriais, sem scripts, fontes externas ou imagens remotas. A silhueta é ilustração decorativa, não visualização de dados. O banner inclui título e descrição acessíveis; os READMEs usam texto alternativo. O símbolo conserva o T e os quatro cantos; não adicionar miras sobre fotografias de pessoas.

## Paleta e significado

| Papel | Cor | Uso |
|---|---|---|
| Fundo | `#0B1112` | Campo principal |
| Superfície | `#13201E` | Cartões e painéis |
| Texto | `#EDF4F2` | Títulos e leitura |
| Texto secundário | `#ACBFBA` | Metadados e contexto |
| Observação | `#58E2C2` | Evidência registrada, nunca sinônimo de verdade |
| Hipótese | `#B7B8FF` | Interpretação em teste |
| Incerteza | `#F3C677` | Cobertura parcial e limites |
| Contradição | `#FF9298` | Evidência contrária e erros de validação |

Cor sempre acompanha rótulo textual. Contradição não significa pessoa perigosa. Não usar escala de cor como escore psicológico.

## Tipografia e composição

Inter / Arial para texto; IBM Plex Mono / Consolas para IDs, tempos e rótulos. Os assets usam fontes genéricas locais para funcionar sem download. Preferir frases curtas, títulos com verbo e registros com origem legível. Em interfaces futuras, corpo mínimo de 16 px, foco visível, navegação por teclado e redução de movimento. A composição do banner usa grade de 64 px e margens generosas; versões pequenas devem usar a marca, não reduzir a capa até tornar o texto ilegível.

## Linguagem dos produtos analíticos

O cartão de achado deve exibir: **observação → evidências → explicações concorrentes → confiança fundamentada → próxima verificação**. Previsões têm janela, probabilidade e critério de resolução próprios. A interface não deve mascarar lacunas com brilho, grafos densos ou indicadores de precisão sem medição.
