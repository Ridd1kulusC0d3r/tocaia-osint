# Synthetic case BX-7

`BX-7` is a fictional institutional-channel example derived from the public teaching version of T.O.C.A.I.A.

The point is not the number `34`. The point is the control:

- **S06** returns zero but has only 30% collection coverage → `data_gap`.

This dataset does **not** represent a real person, company, account or investigation.
