# Public materials policy

The source material used to bootstrap this repository includes conference decks, workshop drafts, a visual README prototype and internal project notes.

Not every source file belongs in a public repository. The release rule is:

- publish synthetic / anonymized teaching material;
- strip direct personal contact information from public decks;
- do not publish material marked restricted without an explicit reclassification;
- do not publish real-person case walkthroughs that would turn a research framework into a targeting playbook;
- prefer a curated public artifact over dumping every working file into `main`.

The initial repository therefore publishes the methodology distilled from those sources, the synthetic BX-7 example and the public reference implementation. Sanitized presentation assets can be added under `materials/presentations/` as separate release artifacts after review.
